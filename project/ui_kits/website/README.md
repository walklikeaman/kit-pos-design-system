# KIT POS Website UI Kit

High-fidelity recreation of the KIT POS marketing website as a click-through prototype.

## Screens covered
1. **Home** — hero, product ecosystem, support block, user stories, FAQ
2. **Partners** — partner benefits, rollout workflow
3. **Platform / Stack** — hardware cards, software capabilities
4. **Solutions** — store category pages
5. **Contact** — form + business details

## Notes
- Built with React + Babel (inline JSX), no build step
- Tailwind CDN used for utility classes that match the source codebase
- All assets referenced from `../../assets/`
- Dark mode toggle is functional (localStorage)
- No real form submission — contact form shows success state only
- Font: Inter via Google Fonts (source codebase uses Tailwind default, Inter is the recommended match)

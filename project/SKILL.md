## Quick reference

**Brand colors:**
- Primary: `#1d3557` (kit-blue)
- Secondary text: `#5f6b7a` (kit-slate)
- Background tint: `#f0f2f5` (kit-mist)
- Border: `#e4e9f0` (kit-border)
- Dark CTA: `#e6eaf0` with `#12161c` text (sky `#0ea5e9` is accent only)

**Font:** Inter (Google Fonts) — variable, opsz 14..32

**Button style:** `rounded-full`, `bg-[#1d3557]`, white text, `hover:opacity-90`

**Card style:** `rounded-[1.75rem]`, `border border-[#e4e9f0]`, `bg-white`, `shadow-[0_8px_30px_rgba(29,53,87,0.08)]`

**Tone:** Calm, direct, practical. No emoji. No hype. Sentence case. Third-person brand references.

**Assets:** See `assets/` folder for logos, hardware photos, software screenshots, payment logos.

**UI Kit:** See `ui_kits/website/index.html` for a full interactive website prototype.
